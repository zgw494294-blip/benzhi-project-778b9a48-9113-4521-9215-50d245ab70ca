# 纺织藏品展陈光照放行台

本项目是面向博物馆纺织藏品保护团队的本地 Web 应用。它把藏品建档、展陈方案修订、光照剂量测算、风险整改、专业复核、证据冻结、凭据签发和公开验真串成一条可追溯流程。

系统按每个照明时段的照度与时长计算日剂量，再结合展期和轮换休息折算预计累计剂量。规则同时检查材料敏感等级的峰值照度、年度剂量上限、紫外防护、轮换安排和脆弱部位证据。每次正式提交都会保存不可变的计算快照与风险发现。

## 构建与测试

项目使用 Go 和嵌入式 SQLite，不需要 Node 构建链或外部服务。

```bash
go build ./...
go test ./...
```

还可以执行带真实回环 HTTP 监听的有界端到端自检。自检使用临时数据库，完成建档、方案测算、送审、批准、签发与验真后自行退出：

```bash
go run ./cmd/server -selfcheck -addr=127.0.0.1:19091
```

## 运行

```bash
go run ./cmd/server -addr=127.0.0.1:19091 -db=textile-permits.db
```

浏览器访问 `http://127.0.0.1:19091/workspace`。默认监听地址为 `127.0.0.1:19091`，可使用 `-addr` 指定其他明确地址。也可设置 `PORT` 为端口号，此时在未传 `-addr` 时监听 `127.0.0.1:<PORT>`。程序拒绝空地址以及 `0.0.0.0`、`::` 等全网绑定地址。

数据库在启动时自动迁移并启用 SQLite WAL。正式写请求均携带 `idempotencyKey`；案卷修改还携带 `expectedVersion`。案卷版本更新、业务记录、幂等结果和连续审计事件在同一短写事务提交。

## 主要操作

1. 在“建立藏品档案”中登记材质、染料敏感性、脆弱部位、历史剂量和年度上限。
2. 在“编制与测算方案”中登记展柜、照度时段、开放时长、展期、轮换和紫外防护。
3. 查看逐项计算结果，对阻断风险登记整改措施与佐证，并按需创建新修订重新测算。
4. 全部阻断项闭环后送审，由不同于申请人的复核负责人批准或带理由退回。
5. 批准会冻结规范化证据清单并签发限时凭据；校验码可在“放行凭据验真”中独立查询。
6. “审计时间线”按数据库连续序号展示案卷的全部变更。

冻结后的案卷不能继续修改。凭据验真会重新校验冻结清单摘要、清单内记录引用、凭据摘要和有效期，响应不会暴露内部整改材料。
